# Actors Studio



Enable **Actors → Actors Studio**. Drag its title bar toward an edge of the
editor or another docked window, then release over a docking guide. It can sit
beside or below the timeline, or share a dock as a tab. Flashback saves the
layout. Actors Studio reuses the native Visuals panel's window identity, so
existing saved layouts still apply.


## Studio tabs

Use **Scene**, **Edit** and **Looks** to access related controls without opening separate floating windows. Keep the studio docked beside the timeline for frequent edits.
