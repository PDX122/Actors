# Captions

Enable captions in Settings, then open **Actors > Subtitles**. Record a take first so the window has an actor to edit.

## Write a caption

Choose the actor and edit its subtitle text, start tick and duration. Caption edits save into the take. Preview the interval on the timeline and check it in the final export.

![Subtitles window with actor and timing controls](assets/screenshots/subtitles.png)

## Style captions

The Settings **Captions** page groups text styling, background, placement and timing. Actor dialogue colors and per-caption options help distinguish speakers.

If the Subtitles window stays closed, confirm captions are enabled. Use [voice recording](voice.md) for audio; text captions do not record a microphone.
