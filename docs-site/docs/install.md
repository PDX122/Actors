# Install

1. Install [Fabric Loader](https://fabricmc.net/use/) 0.16+ and
   [Fabric API](https://modrinth.com/mod/fabric-api) for your game version.
2. Install ![Modrinth](assets/modrinth.svg){ width="14" } [Flashback](https://modrinth.com/mod/flashback) (0.39+, 0.42+ on 26.x).
3. Download the matching jar from
   [GitHub releases](https://github.com/PDX122/Actors/releases) into `mods`.
4. Java 21 runs the 1.21.x jars; the 26.x jars need Java 25.
